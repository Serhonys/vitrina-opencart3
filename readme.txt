Vitrina 1.1 — тема для OpenCart 3 и ocStore 3
================================================

Совместимость: OpenCart 3.0.2–3.0.4, ocStore 3.
Папку catalog/view/theme/vitrina переименовывать нельзя.

Это не покраска default. У страниц своя разметка: vt-page, vt-layout,
vt-products, vt-product, vt-line. Переменные, id форм и скрипты заказа
оставлены штатные, иначе корзина и оформление заказа сломаются.

Своя структура
- шапка, меню, поиск, мини-корзина, подвал, главная
- категория, поиск, акции, производители, сравнение, карточка товара, отзывы
- модули: слайдшоу, баннер, карусель, рекомендуемые, новинки, хиты, акции,
  фильтр, категории, статьи, кабинет, html
- корзина списком, оформление заказа (шаги с прежними id)
- вход, регистрация, кабинет, закладки, адреса, заказы, возвраты
- контакты, статья, карта сайта, 404

Платёжные шаблоны не переписывались: это модули оплаты, не страницы витрины.

Установка
1. Скопируйте содержимое upload/ в корень магазина
   или загрузите zip через Расширения → Установщик.
2. Расширения → Расширения → тип «Темы» → Vitrina →
   Установить → Редактировать → Включено → Сохранить.
3. Система → Настройки → магазин → поле «Тема» → Vitrina.
4. Шестерёнка справа вверху → обновить кэш темы.

jQuery: сначала 3.7 (OpenCart 3.0.4), если файла нет — 2.1.1.
