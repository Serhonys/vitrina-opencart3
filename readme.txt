Vitrina 1.0 — тема для OpenCart 3 и ocStore 3
================================================

Совместимость: OpenCart 3.0.2–3.0.4, ocStore 3.
Папку catalog/view/theme/vitrina переименовывать нельзя.

Установка
1. Скопируйте содержимое upload/ в корень магазина
   или загрузите zip через Расширения → Установщик.
2. Расширения → Расширения → тип «Темы» → Vitrina →
   Установить → Редактировать → Включено → Сохранить.
   При установке размеры изображений записываются сами.
3. Система → Настройки → магазин → поле «Тема» → Vitrina.
4. Шестерёнка справа вверху → обновить кэш темы.

Тема заменяет шапку, подвал и главную-обёртку и перекрывает
стили default: меню, карточки товаров, кнопки, формы, подвал.
Остальные twig берутся из темы default, логика магазина не меняется.
OCMOD нет.

jQuery: сначала 3.7 (OpenCart 3.0.4), если файла нет — 2.1.1.
